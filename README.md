# serial-reader

画像からシリアルコードを読み取り、コピー・CSV出力できる無料Webツールです。

## 公開前の運営設定

- `public/contact.html` は雛形です。一般公開・広告審査へ進む前に、運営者が安全に公開できる問い合わせ窓口を設定してください。
- 問い合わせ先を設定した後は、`contact.html` の `robots` を公開方針に合わせて見直し、必要であれば `public/sitemap.xml` に追加してください。
- 広告やアクセス解析を導入する場合は、実際の利用サービスに合わせて `public/privacy.html` を更新してください。
